# Definition

Projects produce outputs that drive outcomes.

A project is a bounded body of work with a definition of done. Its output is the thing that ships — a feature, a migration, a piece of content, a process change. Shipping the output is not the point; the behavior change it causes is.

Projects can be broken down into other projects--projects can be infinitely nested. A parent project is the whole effort; its children are the slices that can be finished and shipped on their own.

A project that can't name the outcome it drives is a project worth questioning.

# Relationships

Projects can contain one or more projects.

Projects belong to at most one parent project. A project with no parent is a top-level project for its team.

Projects can be connected to one team — the team doing the work.

Projects can be connected to one or more outcomes. One project often moves several outcomes, and one outcome usually needs several projects.

Projects can be connected to one or more insights, which are the evidence that the project should be built.
